### 👋 About

I design and ship complete software for real businesses in Uzbekistan — from the database and API to the mobile app the customer holds and the panel the manager uses every day.

- 🏗️ **End-to-end ownership** — architecture, backend, web & mobile clients, deployment.
- 💳 **Local integrations** — Payme & Click payments, SMS verification, maps, push notifications.
- 🔐 **Correctness first** — double-entry ledgers, idempotent APIs, role-based access, audit logs.
- 🤖 **Automation** — Telegram bots with AI assistants (Gemini, speech-to-text) for staff and clients.
